RAILWAY DEPLOYMENT STEPS:
1. Push the updated .dockerignore to the repository.
2. Trigger a new deployment on Railway (or redeploy the current commit).
3. Railway will rebuild the Docker image (now including the RAG files).
4. The container will start using the startCommand from railway.json.
5. The Property API will be accessible on the assigned port, serving the frontend at root and API routes under /api/.
6. The AI Assistant will work if OPENROUTER_API_KEY is set in Railway environment variables.

ANY REMAINING BLOCKERS:
- The AI Assistant endpoint will return 503 if OPENROUTER_API_KEY is not configured. Set this variable in Railway if the feature is needed.
- Ensure that the RAG_SEMANTIC environment variable is not set to "0" (it defaults to "1"), as this would disable semantic search and fall back to BM25-only mode (still functional but less efficient).
